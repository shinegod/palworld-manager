# huanshou (唤兽) — Palworld Server Management Panel

[中文介绍](README.md)

A PalSupervisor/uMod-class Palworld server management tool: web panel + in-process hook, providing **seamless** online management (no kicking, no restart).

> ⚠️ **AI-Developed Notice**: The vast majority of this project's code was generated by AI assistants, with requirements, architecture decisions, testing and deployment done by the human author. If you don't like it, feel free to move on — **no need to attack the author**. Constructive issues and pull requests are always welcome.
>
> ⚠️ For use **only on servers you own/operate**.

## Architecture

| Component | Path | Description |
|------|------|------|
| palmanager | `cmd/palmanager` + `internal/` | Go Gin backend + embedded Vue3 frontend (port 8080) |
| palhook | `palhook/` | C hook library, injected into PalServer via LD_PRELOAD (port 13335) |
| web | `web/` | Vue3 + Element Plus + TypeScript frontend |

```
Browser ──> palmanager (8080) ──HTTP/BasicAuth──> palhook (13335) ──> everything runs inside the PalServer process
```

**Hook-only architecture**: the panel talks only to PalHook — no official REST API, RCON or Bridge. Player list / metrics / announce / chat / kick / ban / give-item / spawn-pal / exp / level / teleport / tech points / money / guilds are all done in-process by PalHook.

## Compatibility

- Game version: **v1.0.5.102999** (UE 5.1.1). Other versions need offset re-calibration (see palhook/README.md offset table)
- The universal PalHook build works with glibc ≥ 2.14 (any Linux distro since 2011)

## Build

```bash
# Panel (frontend builds & embeds automatically)
make build          # macOS
make build-linux    # Linux amd64 -> bin/palmanager-linux-amd64

# PalHook (build on Linux)
cd palhook
gcc -shared -fPIC -O2 -std=gnu17 -o libpalhook.so palhook.c -lpthread -ldl
```

> ⚠️ **PalHook build warning**: do NOT compile with default gcc on Ubuntu 24.04+ (gcc 15 defaults to C23 and binds `__isoc23_*` symbols requiring GLIBC_2.38). The portable way: build inside the manylinux2014 container (CentOS 7 / glibc 2.17); the binary then requires at most GLIBC_2.14 and loads on any Linux server:
>
> ```bash
> docker run --rm -v $(pwd):/build quay.io/pypa/manylinux2014_x86_64 \
>   bash -c "/opt/rh/devtoolset-10/root/usr/bin/gcc -shared -fPIC -O2 -std=gnu17 \
>   -o /build/libpalhook.so /build/palhook.c -lpthread -ldl"
> ```

## Deploy

Full guide: **[DEPLOY-PRODUCTION.md](DEPLOY-PRODUCTION.md)** (PalHook injection + panel systemd + security + runbook + checklist).

Quick start:

1. **PalHook**: compile `libpalhook.so`, put it in the game directory, add `LD_PRELOAD=/abs/path/libpalhook.so` to the start command (MCSM/Docker alike). AdminPassword is auto-discovered.
2. **Panel**: run `bin/palmanager-linux-amd64 -port 8080`, open `http://<host>:8080`, first login `admin/admin`, fill in the PalHook URL at **Settings → Connection**.
3. **Security**: NEVER expose PalHook port 13335 publicly; change the panel password, nginx + HTTPS recommended.
