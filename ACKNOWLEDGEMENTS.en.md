## Toolchain & frameworks

### PalHook development tools
- **RE-UE4SS** — https://github.com/UE4SS-RE/RE-UE4SS — UE scripting/reflection debugging framework; used in early development to verify UFunction calls and object layouts
- **Dumper-7** — https://github.com/Encryqed/Dumper-7 — UE SDK generator; PalHook's reflection parsing (UClass/UFunction/FProperty/FNamePool layout) follows its SDKGen approach

### Backend dependencies (Go, see go.mod)
Gin, zerolog, golang-jwt, gin-contrib/cors, modernc.org/sqlite, etc.

### Frontend dependencies (see web/package.json)
Vue 3, Element Plus, Vite, Pinia, Vue Router, ECharts, Leaflet + vue-leaflet, Axios, etc.

### Test environment
- **palworld-server-docker** — https://github.com/thijsvanloef/palworld-server-docker — Docker image & deployment used for the test server
- **palworld-save-reader** — https://github.com/LukeHollandDev/palworld-save-reader — save file parsing (used by an earlier version)
